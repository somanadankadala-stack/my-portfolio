# Somanad | Personal Portfolio

A clean, responsive personal portfolio built with modern semantic HTML and CSS.

## 🌐 Live Preview with GitHub Pages
1. Go to your repository on GitHub: [somanadankadala-stack/my-portfolio](https://github.com/somanadankadala-stack/my-portfolio)
2. Click **Settings** > **Pages** (in the left sidebar).
3. Under **Build and deployment > Branch**, select `main` and `/ (root)`.
4. Click **Save**.
5. Your portfolio will be live at: `https://somanadankadala-stack.github.io/my-portfolio/`

## 🛠️ Tech Stack & Highlights
- **HTML5 & CSS3**: Pure modern CSS variables, responsive flexbox layout, smooth scrolling.
- **Typography**: Fredoka & Plus Jakarta Sans via Google Fonts.
- **Color Palette**: Forest green & cream tones (`#12372A`, `#1f4738`, `#FBFADA`).
- **Features**:
  - Hero profile with automatic letter fallback if photo is missing.
  - Interactive skills grid.
  - Featured project idea overview (*Placement Analytics & Skill Gap*).
  - Quick contact links for phone, email, LinkedIn, and GitHub.
